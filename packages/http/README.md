# @nymbalhq/http

The HTTP server under a Nymbal store: Fastify, the security middleware, and the MCP and UCP endpoints agents
call. The `nymbal` CLI mounts it.

See [Agents](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/agents.md) and [Deploying](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/deploying.md).

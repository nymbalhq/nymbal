# nymbal

The Nymbal CLI: `nymbal dev`, `build`, `start`, `deploy`, `add`, `doctor`, `import`, `mcp` and the rest. A store
created with `create-nymbal-app` has it installed; run it with `npx nymbal <command>`.

Every command and flag: the [CLI reference](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/reference/cli.md). Start with the [quickstart](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/quickstart.md).

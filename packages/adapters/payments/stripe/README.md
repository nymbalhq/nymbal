# @nymbalhq/payments-stripe

Stripe payments for Nymbal: the `stripe` payments provider.

```bash
npx nymbal add stripe
```

`nymbal add` installs it, sets it in `nymbal.config.ts` and lists the variables it needs in `.env.example`.
See [Adapters](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/adapters.md).

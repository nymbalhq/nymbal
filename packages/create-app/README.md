# create-nymbal-app

Creates a Nymbal store: an Astro or Next.js storefront, its config, demo products, an admin account and a GitHub
Actions workflow that runs `nymbal verify` on every pull request.

```bash
npx create-nymbal-app my-store
```

Then follow the [quickstart](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/quickstart.md).

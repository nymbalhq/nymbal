# create-nymbal-app

Creates a Nymbal store: an Astro or Next.js storefront, its config, demo products, an admin account, a GitHub
Actions workflow that runs `nymbal verify` on every pull request, and a `renovate.json` that extends Nymbal's Renovate
preset.

```bash
npx create-nymbal-app my-store
```

Then follow the [quickstart](https://github.com/nymbalhq/nymbal/blob/main/apps/docs/src/content/docs/quickstart.md).
